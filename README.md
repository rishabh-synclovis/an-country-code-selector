# an-country-code-selector

Angular workspace for **an-country-code-selector** — a lightweight country code selection dropdown library.

- Library source: [`projects/ngx-country-code-picker`](projects/ngx-country-code-picker) (published npm package name: `an-country-code-selector`) — see its [README](projects/ngx-country-code-picker/README.md) for install/usage docs and the full API.
- Demo app: [`projects/demo`](projects/demo) — run `ng serve demo` and open `http://localhost:4200/` (or the printed port) to try the component live.

## Building the library

```bash
ng build ngx-country-code-picker
```

Artifacts are emitted to `dist/ngx-country-code-picker`, ready for `npm publish` from that directory.
